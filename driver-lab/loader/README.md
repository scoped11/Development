# DriverLabLoader

Borderless splash window: plays `assets/loading_animation.gif` or `loading_animation.mp4` (copy from `dma/assets/` or your Discord clip into `driver-lab/assets/`).

**Actions (admin):**

- **Secure map (RwTest)** — `byovd/map-secure-rwtest.ps1`
- **Rust replica bypass** — `byovd/run-bypass-rust-replica.cmd`
- **R6 replica bypass** — `byovd/run-bypass-r6-replica.cmd`
- **Test R/W** — `byovd/bin/process_rw.exe`

Progress text is shown on the splash while PowerShell runs mapper scripts.
